# Monetization plan

The site is intentionally **monetization-ready, not ad-heavy**.

## Current architecture
- Personal portfolio remains the primary experience.
- Blog is a dedicated content surface.
- Privacy and Terms pages are present.
- Sitemap includes the main content pages.
- No advertising code is placed on the public site yet.

## Future
When an eligible advertising account is available, add the approved publisher code only after completing the provider's requirements and privacy disclosures.

Recommended placement strategy:
1. Keep the homepage clean.
2. Prefer contextual placements on long-form articles.
3. Avoid intrusive layouts that compete with portfolio content.
4. Add the publisher's required `ads.txt` only after receiving the exact publisher record.
5. Re-check privacy/consent requirements whenever analytics or advertising is introduced.

Do not add placeholder publisher IDs to `ads.txt` or advertising scripts.
