# Media library

This folder contains the public visual assets used by `safiullahkorai.com`.

## Recommended structure

- `profile/` — primary professional portraits
- `gallery/` — personal, event and behind-the-scenes photography
- `achievements/` — images that document milestones and awards
- `certificates/` — certificates, letters and other credential documents
- `projects/` — project screenshots and product visuals

## Current imported media

Some images were uploaded before the folder structure was finalized, so the current site keeps their existing paths to avoid breaking references. They are centrally registered in `js/site.js` with descriptive `alt` text.

## Naming convention for future uploads

Prefer descriptive, lowercase, hyphen-separated names, for example:

- `safiullah-korai-profile-2026.jpg`
- `safiullah-korai-openhack-2025.jpg`
- `safiullah-korai-etl-anniversary-2026.jpg`
- `safiullah-korai-ailp-certificate-2026.png`

Use the person's full name in important personal-image filenames where appropriate. This is useful for human organization and gives search engines clearer file context, although filenames alone do **not** determine Google's Knowledge Panel.

## Important

Image filenames are only one signal. The website also uses descriptive `alt` text, page context, structured data, canonical URLs and consistent identity information across the site.
